# DSD-0001: Brand personality — sparse ops cockpit

Mission Control is an **ops cockpit**, not a dense wall of chrome and not a soft consumer toy.

## Feel (locked)

You should feel like you **just unboxed a ZSA Moonlander**: intentional, tactile, engineered, slightly elite—then dropped into a **Minority Report** control room where gestures and focus are precise, not cluttered.

Secondary references for *interaction energy* (not pixel clones):

- **Raycast** — command palette, instant invoke, keyboard-native  
- **Superhuman** — speed, sparse chrome, high signal per pixel  

## Layout lineage (locked metaphor)

| Layer | Who “did it” in the fantasy brief |
|-------|-----------------------------------|
| Structure / IA | **Apple** layout discipline |
| Spacing & radii | **Jony Ive** restraint—generous air, perfect corners |
| Controls | **Icon Factory**–grade interface buttons (crafted, iconic, not generic Material blobs) |
| Glow / juice | **COD Mobile** team “glow-up”—neon edge light, premium game UI polish without arcade chaos |

## Density

- **Sparse, not dense.** Cockpit ≠ dashboard packed with widgets.  
- Prefer fewer surfaces, more breathing room, progressive disclosure.  
- Agency power users get depth via command palette / detail panels, not permanent clutter.

## Voice (seed)

- Confident, precise, operational.  
- Avoid: cutesy, “growth hacker” slang, enterprise beige blandness.  
- Prefer: short labels, verbs that match the domain glossary (`Crawl Run`, `Conversation`, `Project`).

## Not this product

- BreezyApp-friendly DIY local-business softness (different product).  
- Pure Catppuccin rice without glass/glow craft.  
- Dense GHL-era admin tables as the default aesthetic (function may need tables; presentation stays sparse).
