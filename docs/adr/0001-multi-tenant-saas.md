# Multi-tenant SaaS for agencies from day one

Product posture is a multi-tenant SaaS sold to digital marketing / local SEO agencies—not a single-agency internal tool. Tenancy, isolation, and agency-as-customer are foundational constraints, not a later retrofit.

**Considered:** single-agency internal tool (faster ship); hybrid “dogfood first, multi-tenant later” (risk of wrong data model). Chose full multi-tenant SaaS because the target shape is GHL/HubSpot-class agency software and Org boundaries must be correct early.
