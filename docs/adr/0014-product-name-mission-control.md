# Product name: Mission Control

The shipping product name is **Mission Control**. Repository path may remain `mission-control-os` as a technical codename; user-facing Surfaces, docs, and packages use Mission Control.

## Why

Chosen as the brand identity for the multi-surface local SEO / digital agency OS (Control Plane + Agent + Audit Loop). Evokes a single ops hub coordinating Sites, Crawl Runs, and findings across Web, Desktop, TUI, and Mobile.

## Notes

- Apple uses “Mission Control” for a macOS window-management feature—accept brand-collision risk or pair with a house brand (e.g. studioTWELVE Mission Control) in legal/marketing later.
- Internal BreezyApp notes historically used “Mission Control” for a dashboard concept; this ADR claims the name for **this** agency OS product unless later split.

## Consequences

- Rename user-facing strings and package scopes to Mission Control as implementation starts.
- Domains/trademarks TBD (not decided here).
