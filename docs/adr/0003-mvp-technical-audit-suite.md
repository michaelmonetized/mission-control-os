# MVP wedge: technical audit suite (crawl + duplicates + accessibility)

v1 is a **technical audit suite** scoped to Sites under the Agency → Client → Location tree: site crawl, duplicate/thin-content detection, and accessibility checks. This is the foundational delivery surface agencies run before citations, links, CRM, social, or full marketing automation.

**Why this wedge:** user judgment that an agency-native, multi-tenant audit OS (not a desktop crawler) is underserved; audits are prerequisite work for local SEO retainers and feed every later module.

**Explicitly deferred from v1:** citation acquisition tracker, link-building tracker, Buffer-class social, HubSpot/GHL-class CRM/automation, and a rich client analytics portal (may ship a minimal portal later, not as the wedge).

**Considered:** local SEO delivery core (citations/links); client portal + analytics cache; GHL-lite CRM; social scheduling. Rejected for v1 in favor of technical foundations.
