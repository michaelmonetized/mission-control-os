# Design scope expands beyond technical audit wedge

Grilling continues for **agency operating capabilities** beyond the technical audit suite already ADRd: CRM, task queue, API structure, naming conventions, email, social calendar, connectivity/integrations, onboarding flows, and related Control Plane concerns.

ADR-0003 still describes the **first ship wedge** as technical audit unless later ADRs promote other modules into the same release. This ADR only opens the design surface—it does not by itself put CRM/email/social in the same binary MVP as crawl.

Further ADRs will pin each module’s MVP inclusion and shape.
